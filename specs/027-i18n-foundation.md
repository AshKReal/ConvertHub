## Задача

Три языка интерфейса — русский, украинский, английский — с автоматическим выбором по стране пользователя и ручным переключателем. Строки выносятся в словарь с самого начала: экраны, написанные с текстом внутри разметки, потом переписываются целиком, а их к стадии 3 будет десять.

## Входит

- Локали `ru` / `uk` / `en`, английская — умолчание
- Автоопределение: Россия → русский, Украина → украинский, остальной мир → английский
- Определение страны без сети: часовой пояс, затем регион языкового тега браузера
- Ручной переключатель в шапке, выбор сохраняется в `localStorage` и имеет приоритет над автоопределением
- Английский словарь — источник ключей, остальные типизированы через него: забытый перевод не компилируется
- Подстановка чисел и значений в строку через плейсхолдеры `{name}`
- Атрибут `lang` на `<html>` и заголовок вкладки следуют за выбранной локалью
- Все существующие экраны (главная, страница конвертации, шапка) переведены на все три языка

## Не входит

| Что | Где будет |
|---|---|
| Тексты по кодам ошибок с конкретными числами | 004 |
| Локаль в адресе (`/ru/...`), SEO и SSR | Отдельная спека, если появится требование |
| Форматирование дат, чисел и размеров файлов по локали | 021 (`formatBytes`), при появлении списка файлов |
| Определение страны по IP на бэкенде | Отдельная спека, если точности часового пояса не хватит |
| Множественные формы («1 файл / 2 файла / 5 файлов») | 021, где впервые появляются счётчики |

## Поведение

- Когда пользователь из России открывает сайт впервые, интерфейс на русском.
- Когда пользователь из Украины открывает сайт впервые, интерфейс на украинском.
- Когда пользователь из любой другой страны открывает сайт впервые, интерфейс на английском.
- Когда пользователь нажимает `EN` в шапке, весь интерфейс переключается без перезагрузки, и выбор переживает перезагрузку и смену страницы.
- Когда выбранная локаль меняется, `<html lang>` и заголовок вкладки меняются вместе с ней.
- Когда `localStorage` недоступен, переключатель продолжает работать в пределах сессии.
- Когда часовой пояс не определяется, решение принимается по языковым тегам браузера, затем — английский.

## Ошибочные сценарии

Экран не обращается к сети. Отказы касаются только источников определения локали, и каждый разрешается следующим источником.

| Ситуация | Что видит пользователь | Код |
|---|---|---|
| `localStorage` заблокирован | Язык по автоопределению; выбор не переживает перезагрузку | — |
| `Intl` не отдаёт часовой пояс | Язык по региону языкового тега, иначе английский | — |
| В хранилище лежит неизвестная локаль | Автоопределение, значение игнорируется | — |

## План

### Подход

Словарь плоский: ключ вида `home.title` → строка. Английский файл объявлен через `as const`, из него выводится `MessageKey`, русский и украинский типизированы как `Record<MessageKey, string>` — пропущенный или лишний ключ ловится компилятором, а не глазами на ревью.

Локаль — сигнал в сервисе `core`. Компоненты вызывают `i18n.t('ключ')` прямо в шаблоне: вызов читает сигнал, поэтому смена языка перерисовывает `OnPush`-компонент без единой подписки. Пайп для этого не годится — чистый пайп кеширует результат по аргументам и на смену локали не среагирует.

Страна определяется офлайн. Основной признак — часовой пояс (`Intl.DateTimeFormat().resolvedOptions().timeZone`) со списком зон России и Украины по tzdb, включая устаревшие имена, которые ещё отдают старые браузеры. Запасной — регион языкового тега (`ru-RU`, `en-UA`). Язык системы используется последним: английская Windows у пользователя из России не должна уводить его на английский интерфейс.

Описание направления конвертации связывается с идентификатором из `packages/shared` явной таблицей, а не склейкой ключа из строки: склейка компилируется при любой опечатке, таблица — нет.

### Затрагиваемые файлы

- `apps/web/src/app/core/i18n/locale.ts` — новый
- `apps/web/src/app/core/i18n/messages.ts` — новый

### Отвергнутые варианты

| Вариант | Почему отвергнут | Когда вернёмся |
|---|---|---|
| Встроенный `@angular/localize` | Сборка на каждый язык и перезагрузка страницы при переключении; строки живут в XLIFF, а не в TypeScript, и компилятор не ловит пропуски | Если понадобится SSR с раздачей по домену на язык |
| Библиотека (`transloco`, `ngx-translate`) | Зависимость и JSON-словари без проверки ключей ради того, что здесь занимает три файла | Когда языков станет больше пяти или переводы отдадут наружу |
| Определение страны по geo-IP | Сеть на первой отрисовке, чужой сервис в критическом пути, IP уходит третьей стороне; фронтенд-фаза строится без сети | Если офлайн-определение начнёт ошибаться на реальных пользователях |
| Локаль префиксом в адресе (`/ru/convert/...`) | Переписывание всех маршрутов и ссылок ради SEO, которого на стадии 0 ещё нет | Вместе с SSR или требованием индексации по языкам |
| Пайп `{{ 'home.title' \| t }}` | Чистый пайп кеширует по аргументам и не реагирует на смену локали; нечистый — вызов на каждую проверку | Никогда |

### Риски и границы транзакций

БД не затрагивается. Риски:

- Часовой пояс — не страна. Пользователь из России в поездке получит английский; переключатель это лечит, автоопределение — нет.
- `Europe/Simferopol` отнесён к Украине, как в tzdb. Решение зафиксировано явно, чтобы не переоткрывать его при каждом чтении списка.
- Список зон нужно обновлять вслед за tzdb: появившаяся зона молча попадёт в английский.
- Ключи словаря — строковые литералы в шаблонах, и `strictTemplates` их проверяет, а вот удаление ключа из английского словаря ломает сборку только там, где он используется.

### Мои тест-кейсы

- Часовой пояс `Europe/Moscow`, язык системы английский, чистое хранилище — русский интерфейс
- Часовой пояс `Europe/Berlin`, язык системы русский — английский интерфейс (страна важнее языка)
- Часовой пояс `Europe/Kiev` (устаревшее имя) — украинский
- В хранилище `"de"` — автоопределение, приложение не падает
- Выбран `EN`, переход на `/convert/docx-to-pdf` и обратно — язык не сбросился
- Переключение языка в тёмной теме — тема не сбросилась, активная кнопка видна
- Украинский язык, ширина 320px — самая длинная надпись не ломает шапку и карточки
